- `custom data arrtibutes` (data-* attribute) in html tags are used to toggle the theme in this project.

- Other than `custom data attributes`, only a Ternory operator, useState and `custom properties CSS` (also known as CSS variables var(--background)) are used for dark and light mode styling.

- `useLocalStorage()` a custom hook was also used in this project.

- we can use useLocalStorage() with `key` and a `defaltValue` as parameters, but instead we used simple useLocalStorage() without any parameter to keep the project simple.
